# Holberton School — Back-end web development

Coursework from Holberton School's software engineering program (2024–2026).

## Projects

- JavaScript (ES6): `ES6_basic`, `ES6_classes`, `ES6_promise`, `ES6_data_manipulation`
- Node.js: `Node_JS_basic` (modules, file reading, HTTP and Express servers), `unittests_in_js` (Mocha, Chai, Sinon), `queuing_system_in_js` (Redis client and Kue job queues)
- Python typing and async: `python_variable_annotations`, `python_async_function`, `python_async_comprehension`
- Python back end: `caching` (FIFO, LIFO, LRU, MRU, LFU caches), `pagination`, `personal_data` (log redaction, bcrypt), `0x0B_redis_basic` (Redis with Python), `i18n` (Flask-Babel)
- Authentication with Flask: `Basic_authentication`, `Session_authentication`, `user_authentication_service` (Flask, SQLAlchemy, bcrypt)
- Testing: `Unittests_and_integration_tests` (`unittest`, `parameterized`, mocks)
- Databases: `MySQL_Advanced` (constraints, indexes, procedures, functions, views, triggers), `NoSQL` (MongoDB shell and PyMongo)

## Languages and tools

JavaScript (Node.js, Babel, ESLint), Python 3, SQL, Flask, Redis, MongoDB, MySQL.

Each project folder has its own README with requirements and usage.
